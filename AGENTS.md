# Project development preferences

- Assist with development through focused code/documentation edits and concise
  explanations of what changed and why.
- The maintainer normally conducts testing. Do not run builds or automated tests,
  or launch Minecraft clients, servers, or worlds, unless directly requested by
  the user for the current task. Read-only file and Git inspection is allowed.
- Provide manual verification instructions and clearly state any unverified
  behavior. Avoid lengthy optional validation or environment troubleshooting.
- Preserve existing aggression/movement behavior during compatibility hotfixes;
  unfinished AI and faction development requires an explicit request.
