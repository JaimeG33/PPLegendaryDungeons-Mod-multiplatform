# v1.1.3 — Cobblemon 1.8.2 compatibility hotfix

- Updates the compatibility target to Cobblemon 1.8.2 on Minecraft 1.21.1.
- Updates the recommended Mega Showdown dependency to
  **1.3.0+1.8.2+1.21.1-hotfix**, published October 12, 2026.
  Use [Fabric file 9146466](https://www.curseforge.com/minecraft/mc-mods/cobblemon-mega-showdown/files/9146466)
  or [NeoForge file 9146465](https://www.curseforge.com/minecraft/mc-mods/cobblemon-mega-showdown/files/9146465).
- Allows compatible later Cobblemon 1.8.x and Mega Showdown 1.3.x patches.
  Those patches are not automatically considered tested; use the recommended
  hotfix rather than the initial Mega Showdown 1.3.0 release.
- Preserves existing gameplay, dungeon content, save identifiers, and encounter
  behavior. No new AI, movement, faction, or raid features are included.

Install the file for your loader with the required Architectury and dependency
mods. Cobblemon and Mega Showdown are separate downloads, not bundled.

Known limitations: the experimental faction/aggression overhaul remains paused,
including existing pursuit/attack problems. Crystal Caves remains dormant.
